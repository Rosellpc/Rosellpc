## Proyectos destacados

### RestaurantOS

MVP de gestión gastronómica que conecta el menú y los pedidos con Cocina, Barra, inventario y costeo de recetas.

**Mi aporte:** frontend, backend, modelado de datos y flujos del cliente y del personal. Incluye permisos por rol, operaciones transaccionales para stock y cálculos decimales para importes.

**React · TypeScript · Django REST Framework · PostgreSQL · Supabase**

Estado: MVP en entorno local; modalidad SaaS prevista.

[Caso de estudio](https://roseell.com/proyectos/restaurantos/)

### Focus

Aplicación de hábitos, temporizador y reportes para Windows y Android, con datos locales y uso sin conexión.

**Mi aporte:** interfaz e integración con Tauri, Rust y SQLite, incluidos respaldo y restauración transaccional para conservar el historial.

**React · TypeScript · Tauri · Rust · SQLite**

Código e instaladores disponibles en GitHub.

[Código](https://github.com/Rosellpc/Focus) · [Descargas](https://github.com/Rosellpc/Focus/releases) · [Caso de estudio](https://roseell.com/proyectos/focus/)

### Memely News

Búsqueda de noticias y consultas con IA desde una interfaz web o una CLI, con fuentes consultables y control de uso.

**Mi aporte:** API, interfaz web, CLI e integración de fuentes y proveedores de IA. Lógica compartida entre web y CLI y límites de uso mediante Redis.

**Python · FastAPI · JavaScript · Redis · OpenAI · Gemini**

[Demo](https://memely-news.vercel.app/) · [Caso de estudio](https://roseell.com/proyectos/memely-news/)
